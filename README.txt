📥 설치 방법 (How to Install):

1. 압축을 해제한 후, 폴더 내 파일을 아래 경로에 넣어주세요:  
   ▶ 붕괴: 스타레일 → \SRMI\Mods  
   ▶ 원신 → \GIMI\Mods

2. 게임을 재실행하면 모드가 적용됩니다.

1. Unzip the files and place them in the following folder:  
   ▶ For Star Rail → \SRMI\Mods  
   ▶ For Genshin Impact → \GIMI\Mods

2. Restart the game to apply the mod.
